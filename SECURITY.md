# Security policy

FlowDoc records your screen and keyboard during a capture, and can store an AI key and a Notion secret. Security problems are taken seriously.

## Supported version

Only the [latest release](https://github.com/avin045/FlowDoc/releases/latest) receives security fixes.

## What to report

For example:

- your AI key or Notion secret leaving your computer other than to the provider you chose;
- a password appearing in a guide, a screenshot or an export;
- FlowDoc recording anything when no capture is running;
- code running when a guide or backup file is opened or imported.

## How to report

Report it privately: on the repository page, go to **Security** → **Report a vulnerability**. Please don't open a public issue, so the problem isn't exposed before it's fixed.

Include what you did, what happened, and which FlowDoc version and operating system you used.

## What happens next

FlowDoc is maintained by one person. Reports are answered on a best-effort basis, with no fixed timeframe. Confirmed problems are fixed in a new release.
